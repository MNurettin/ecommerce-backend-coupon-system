# E-Commerce Backend — Backend Coupon system

## 🇹🇷 Türkçe

Projenin başlangıç noktası, temel e-ticaret işlemlerini gerçekleştiren mevcut bir ASP.NET Core Web API projesidir. Başlangıçtaki örnek yapı ve kodların bir kısmı AI desteğiyle oluşturulmuştur, üzerine kupon sistemi eklenmiştir.

Simülasyon kapsamında mevcut sisteme yeni bir iş gereksinimi olarak **Coupon System (Kupon Sistemi)** eklenmiştir.

### Eklenen Kupon Sistemi

* Sepet bazlı ve ürün bazlı kuponlar
* Yüzdelik ve sabit tutarlı indirimler
* Kupon başlangıç ve bitiş tarihleri
* Kullanım limiti
* Kupon kullanım takibi
* Ürün–kupon ilişkisi
* Backend tarafında kupon doğrulaması
* Sipariş oluşturulurken kupon uygulanması
* Eşzamanlı kupon kullanımlarında kullanım limitinin korunması

### Teknolojiler

* C#
* ASP.NET Core Web API
* Entity Framework Core
* SQLite

---
## 🇬🇧 English

The starting point of the project is an existing ASP.NET Core Web API project that performs basic e-commerce operations. Part of the initial sample structure and code was generated with AI assistance, and a coupon system has been built upon it.

Within the scope of the simulation, a **Coupon System** has been added to the existing system as a new business requirement.

### Added Coupon System

* Cart-based and product-based coupons
* Percentage and fixed-amount discounts
* Coupon start and end dates
* Usage limit
* Coupon usage tracking
* Product-coupon relationship
* Coupon validation on the backend side
* Applying coupons during order creation
* Protection of the usage limit during concurrent coupon uses

### Technologies

* C#
* ASP.NET Core Web API
* Entity Framework Core
* SQLite
